# 🎂 Bam's Day - Care Bears Birthday Special 🌈🐻

A heartfelt Care Bears interactive birthday experience built with love for Bam-Bam (October 4th).

## ✨ Features

1. 🎁 **Scene 1: Care-a-Lot Magical Gift Box** - Interactive unboxing with confetti explosion.
2. 🌈 **Scene 2: Welcome to Care-a-Lot** - Vibrant Care Bears welcome and birthday introduction.
3. 📸 **Scene 3: Duo Polaroid Envelope** - Envelope opening revealing boyfriend's funny face (`24427.jpg`) on the left and a live selfie booth / photo upload on the right, merging into a downloadable keepsake polaroid.
4. 🎂 **Scene 4: Cake & Candle Blow** - Interactive 3D birthday cake with realistic blow-out flame and smoke animation.
5. 🃏 **Scene 5: Care Bears Birthday Tarot Deck** - Interactive card shuffle, fanned card picker, 3D card flip reveal (Love 💕, Energy ☀️, Birthday Luck 🌟), and instant high-res card image saving.
6. ⚡ **Scene 6: Thunder Heart Libra Oracle** - 20 lucky celestial symbols dedicated to Libra (Oct 4). Pure divine prophecy from Thunder Heart Bear herself with downloadable divination cards.
7. 💌 **Scene 7: Love Letter & Big Hug** - Sincere letter from boyfriend to Bam-Bam with heart explosion animation.

## 🚀 How to Run Locally

You can serve this project using Node.js:

```bash
node server.js
```

Or open `index.html` directly in any modern web browser or mobile browser (iPhone / iPad Safari & Chrome fully supported).
